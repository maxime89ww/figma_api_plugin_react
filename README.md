# Figma API Image Generator

Плагин для генерации и редактирования изображений в Figma через Polza AI.

Модели: **Nano Banana 2**, **Nano Banana 2.1**, **GPT Image 2**. Разрешения: 1K / 2K / 4K.

## Установка без сборки

Готовая сборка включена в репозиторий — устанавливать Node.js, VS Code и пакеты не нужно.

1. Нажмите **Code → Download ZIP** и распакуйте архив целиком.
2. Откройте Figma Desktop и любой дизайн-файл.
3. Выберите **Plugins → Development → Import plugin from manifest**.
4. Укажите `manifest.json` из распакованной папки. Папка `dist` должна оставаться рядом с ним.
5. Запустите **Figma API Image Generator** через меню Development.
6. Нажмите значок ключа и введите собственный API-ключ Polza AI.

Ключ сохраняется локально средствами Figma. Генерации оплачиваются с вашего баланса Polza AI.

## Использование

- Выберите модель и разрешение 1K / 2K / 4K.
- Опишите изображение. Для точного формата напишите числовое соотношение сторон, например: **«Предметная фотография, соотношение сторон 16:9»**.
- Можно указать размер в пикселях: `1200х900`, `1200x900`, `1200×900` или `1200 на 900` преобразуются в `4:3`; `1920×1080` — в `16:9`.
- Размер в пикселях задаёт пропорции. Реальное разрешение генерации определяется переключателем 1K / 2K / 4K и стандартными размерами модели. Ровно 1200×900 требует отдельного ресайза.
- Последнее числовое указание формата используется для запроса. Если пиксельные размеры дают неподдерживаемые пропорции, плагин показывает ошибку до отправки генерации. Без указания формата используется `auto`.
- Для Nano Banana 2.1 дополнительно доступны форматы 1:4, 4:1, 1:8 и 8:1.
- Добавьте референсы загрузкой или выделите изображение на холсте для редактирования.
- Нажмите **Harvest!** или **Edit image**.

При долгой генерации плагин ожидает статус до 10 минут. При таймауте проверьте задачу в кабинете Polza перед повторной генерацией: она может продолжать выполняться.

## Разработка

Для изменения исходников установите Node.js 22.12+ и выполните:

```bash
npm ci
npm run test
npm run build
```

После изменений коммитьте исходники и обновлённые `dist/ui.html` и `dist/plugin/code.js`: так скачанный плагин останется готовым к запуску.

Для локальной разработки интерфейса:

```bash
npm run start
```
